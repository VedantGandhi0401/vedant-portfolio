% Controls which bullet points, skills, coursework, and
% achievements appear throughout the entire resume.

%   FullStack    → Full Stack Engineer
%   SRE          → Site Reliability Engineer
%   DevOps       → DevOps / Infrastructure Engineer
%   Cloud        → Cloud Engineer
%   Security     → Security Engineer
%   MLOps        → ML Operations Engineer
%
%   --- Data & AI ---

%   Data         → Data Engineer / Analytics Engineer

%
%   --- Quant & Finance ---
%   Quant        → Quantitative Analyst (general)
%   QuantResearch → Quantitative Researcher
%   QuantTrader  → Quantitative Trader
%   Finance      → Finance / Investment roles
%
%   --- Business ---
%   Consulting   → Management / Business Consulting
%
%   --- NPCI ---
